# AI YouTube Video Analyzer 🎥

An AI-powered application that analyzes YouTube videos and generates insights from available transcripts using Large Language Models (LLMs).

🔗 **Live Demo:** https://youtube-video-analyzer-saurabh.streamlit.app/

## Features
- Analyze YouTube videos using their URLs.
- Generate AI-powered insights from video transcripts.
- Interactive web interface built with Streamlit.
- Deployed on Streamlit Community Cloud.

## Tech Stack
- Python
- Streamlit
- Groq API
- Agno AI Agent Framework
- YouTube Tools

## Installation & Setup

**1. Clone the repository**
```bash
git clone https://github.com/saurabhdhule2005/youtube-video-analyzer.git
cd youtube-video-analyzer
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```

**3. Configure your API key**

Create a `.env` file in the project directory and add:

```env
GROQ_API_KEY=your_api_key_here
```

**4. Run the application**
```bash
python -m streamlit run ui.py
```
